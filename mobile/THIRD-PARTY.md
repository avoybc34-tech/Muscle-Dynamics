# Third-party code and artwork

Dependencies use their upstream licenses; exact versions/resolution are in package.json and package-lock.json. Main libraries: Expo, React, React Native, expo-font, expo-system-ui, SecureStore, ImagePicker, safe-area context, and Ionicons via @expo/vector-icons. Preserve their license notices when distributing built apps.

The included MD app icons are new simple typographic artwork rendered locally for this project. No registered-trademark status or ownership of a matching internet domain is asserted. There are no gym photographs, invented member/trainer profiles, prices or payment details in this mobile repository.

The Android native template generates a publicly known debug/test keystore during prebuild. It is intentionally NOT a production secret or signing identity. No private signing keys are included in the source ZIP.
