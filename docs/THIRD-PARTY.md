## Code libraries
Website/backend uses Next.js, React, Prisma, Zod and Sharp. Native app uses Expo, React Native, SecureStore, ImagePicker, safe-area context and Ionicons via `@expo/vector-icons`. Dependency versions are recorded in each package.json/package-lock.json. Their respective upstream licenses apply; keep npm package license notices when distributing built products. Lockfiles do not replace a release-specific license/security review. The source ZIP intentionally excludes node_modules and generated bundles/binaries.
