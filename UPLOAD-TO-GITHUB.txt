1. Extract this ZIP. Open the muscle-dynamics-github folder.
2. On github.com create a NEW empty repository in your account.
3. Add file -> Upload files -> drag ALL contents of this folder, including .github.
   Do not upload the ZIP file; do not wrap the files inside another mobile folder.
4. Commit to the repository's default branch.
5. Actions -> Build APK and unsigned IPA -> Run workflow.
6. Choose both / android / ios. Backend URL is optional.
7. Tick the TESTING acknowledgement, then Run workflow.
8. Open the finished run -> Artifacts -> download and unzip the selected result.

Correct repository layout:
  .github/workflows/build.yml
  package.json
  package-lock.json
  app.json
  App.tsx
  src/
  scripts/
  assets/
  ...

APK: installable Android test app, public test signing key.
IPA: UNSIGNED. NOT normally installable on an iPhone until separately signed.
No Expo or Apple account/signing secrets needed for these two workflow outputs.
GitHub Actions availability, quotas/charges and source privacy are your responsibility.

If Run workflow is missing: confirm the .github path, default branch, and Actions enabled.
If build fails: download its build-logs artifact and share the first actual error section.
Do NOT share account tokens, database passwords, signing keys or private .env files.
